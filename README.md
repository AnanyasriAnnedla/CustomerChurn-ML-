# CustomerChurn-ML-

PROJECT OVERVIEW
This project predicts whether a customer will leave a telecom service, (called as churn), using Machine Learning techniques. It helps companies identify the customers who have a high churn rate, and take preventive actions.

OBJECTIVE
To build classification model that predicts customer churn based on customer data such as tenure, services used, and billing information.

DATASET
Telco Customer Churn
Source: Kaggle

TECHNOLOGIES USED
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

PROJECT WORKFLOW
1.Data Collection
2.Data Cleaning
3.Data Preprocessing
4.Feature Encoding
5.Train-Test Split
6.Model Training
7.Model Evaluation
8.Visualization

Model Used: Logistic Regression

RESULTS
Accuracy: 81%
Confusion Matrix:
[[933 103]
 [151 222]]

Conclusion
The model successfully predicts customer churn with good accuracy. This can help businesses improve customer retention strategies.
